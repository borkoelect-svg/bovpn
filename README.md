# BoVPN

**BoVPN** — простое приложение для Windows и Android, которое работает с
бесплатными публичными серверами [VPN Gate](https://www.vpngate.net/).
Русскоязычный интерфейс, встроенные протоколы Windows, необязательный OpenVPN
и экспорт профилей на Android. Без подписок, аккаунтов и пользовательской
инфраструктуры.

![Главное окно BoVPN](docs/screenshot-main.png)

## Важное предупреждение

> Публичные VPN-серверы поддерживают волонтёры. **Оператор сервера может видеть,
> какие сайты вы посещаете, и в теории — перехватывать незашифрованный трафик.**
>
> Не используйте BoVPN для банковских операций, государственных порталов,
> рабочей почты, ввода паролей и любых конфиденциальных данных. Сервис не даёт
> гарантий скорости, доступности и безопасности. Используйте его осознанно и с
> соблюдением законов вашей страны.

## Обход блокировок в России

Публичные серверы VPN Gate не рассчитаны на обход государственных блокировок:
адреса и типовые порты быстро попадают в DPI-фильтры. BoVPN — каталог и
удобная обвязка, а не гарантия доступа.

Что бесплатно помогает чаще:

1. **Psiphon** — клиент с обфускацией; в Android-версии BoVPN есть кнопка
   запуска. Без лимита трафика, но с рекламой и невысокой скоростью
   ([psiphon.ca](https://psiphon.ca/)).
2. **Tor/Orbot с мостами** — медленно, зато рассчитан на цензуру. В Orbot
   включите мосты obfs4 или Snowflake ([orbot.app](https://orbot.app/)).
3. **OpenVPN Connect + профиль VPN Gate** — если провайдер ещё не режет
   OpenVPN на конкретном сервере.

Более устойчивый вариант — свой VPS за рубежом с VLESS/REALITY (Xray) или
Shadowsocks-2022. Это стоит около 300–500 ₽/мес и требует настройки. Платные
VPN с обфускацией — компромисс между ценой и удобством.

## Возможности

- Список серверов VPN Gate с поиском, фильтрами по стране и OpenVPN,
  сортировкой по пингу/скорости/сессиям.
- **SSTP** — основной режим, работает через TCP 443 без сторонних программ.
- **L2TP/IPsec** — запасной встроенный протокол Windows.
- **OpenVPN** — необязательный режим при установленном OpenVPN Community Edition.
- Подключение и отключение через `rasdial`, создание VPN-профиля Windows.
- Свой источник CSV/JSON в формате VPN Gate и добавление серверов вручную.
- Кэш списка серверов, работа при недоступном API, журнал событий.
- Тёмная тема, статус подключения, внешний IP, демо-режим для проверки UI.
- Никаких сторонних библиотек во время работы: только Python + Tkinter.
- Готовый `dist\BoVPN.exe` — Python для запуска не нужен.
- **Android:** каталог серверов, поиск, фильтр стран и экспорт `.ovpn`
  в OpenVPN Connect; кнопки Psiphon и Tor/Orbot для России.
- Готовый `dist\BoVPN-android.apk` для Android 8.0+.

## Требования

- Windows 10 или Windows 11 (x64).
- Android 8.0+ (API 26) для APK.
- Для EXE: ничего дополнительно.
- Для запуска из исходников: Python 3.10+ с Tkinter (входит в стандартный
  установщик Python для Windows).
- Интернет для загрузки списка серверов и подключения.
- Права администратора **не нужны для запуска приложения**, но Windows запросит
  UAC при создании VPN-профиля и при запуске OpenVPN.

## Быстрый старт

1. Запустите `dist\BoVPN.exe` (или `BoVPN.bat`, или `python -m bovpn`).
2. Прочитайте предупреждение и нажмите «Принимаю».
3. Выберите страну и сервер в таблице слева.
4. Оставьте протокол **SSTP**, если нет причин менять его.
5. Нажмите «Подключиться» и подтвердите запрос UAC.
6. После подключения статус сменится на «Подключено», а внешний IP обновится.
7. Для выхода из VPN нажмите «Отключиться».

Логин и пароль для серверов VPN Gate: **`vpn` / `vpn`**. Ключ L2TP/IPsec:
**`vpn`**. Эти данные уже подставлены автоматически.

## Android-версия

`dist\BoVPN-android.apk` — приложение для Android 8.0+. Оно показывает те же
публичные серверы VPN Gate, ищет по стране и хосту и собирает безопасный
`.ovpn`-профиль. **Собственного туннеля в APK нет:** подключение выполняет
установленный OpenVPN Connect, поэтому не нужны root и системные разрешения.

1. Установите `dist\BoVPN-android.apk` и разрешите установку из неизвестных
   источников.
2. Примите предупреждение.
3. Выберите сервер с отметкой «OpenVPN».
4. Нажмите «Открыть» и подтвердите импорт в OpenVPN Connect. Кнопка
   «Сохранить» кладёт `.ovpn` в выбранную папку.
5. Подключитесь в OpenVPN Connect.

Если OpenVPN Connect не установлен, BoVPN предложит перейти в магазин или
поделиться файлом `.ovpn`, чтобы импортировать его вручную.

Для России в приложении есть отдельный блок:

- **Psiphon** — бесплатный клиент с обфускацией, обычно устойчивее к DPI
  ([psiphon.ca](https://psiphon.ca/));
- **Tor/Orbot** — резервный вариант, медленнее, помогает с мостами
  ([orbot.app](https://orbot.app/));
- **OpenVPN Connect** — для профилей VPN Gate, если сеть их пропускает.

> В России VPN Gate и OpenVPN могут блокироваться провайдером. Самый
> доступный бесплатный вариант с обфускацией — Psiphon; резерв — Tor/Orbot.
> Proton VPN и Windscribe предлагают Stealth на части тарифов, но доступность
> зависит от тарифа и страны. Устойчивее всего собственный VPS с VLESS/REALITY,
> но это уже не бесплатно.

## Протоколы

| Протокол | Транспорт | Адрес сервера | Особенности |
|---|---|---|---|
| **SSTP** | TCP 443 | Доменное имя `*.opengw.net` | Рекомендуется. Лучше проходит блокировки, сертификат проверяется по имени. |
| **L2TP/IPsec** | UDP 500/4500 | IP-адрес | Иногда блокируется провайдером. PSK: `vpn`. |
| **OpenVPN** | TCP/UDP из профиля | IP-адрес | Нужен установленный OpenVPN Community Edition и адаптер TAP-Windows. |

BoVPN создаёт в Windows одно VPN-подключение с именем **BoVPN** и при смене
сервера пересоздаёт его. Поэтому при переключении серверов может появляться
запрос UAC. Приложение не запрашивает постоянные права администратора.

### OpenVPN

OpenVPN-профили VPN Gate не запускаются «как есть». BoVPN собирает новый
конфигурационный файл только из проверенных параметров: адрес сервера, порт,
шифры и встроенные сертификаты. Директивы `plugin`, `script-security`, `up`,
`down`, `route-up` и подобные отбрасываются.

Если OpenVPN не найден, кнопка режима предложит скачать официальный установщик
или переключиться на SSTP. После установки OpenVPN перезапустите BoVPN.

## Интерфейс

- **Поиск** — по стране, хосту, IP и оператору; несколько слов работают как
  фильтр «И».
- **Страна / OpenVPN** — быстрые фильтры списка.
- **Заголовки таблицы** — сортировка; повторный клик меняет направление.
- **Случайный** — выбирает один из самых быстрых видимых серверов.
- **Свой сервер** — открывает настройки для добавления адреса вручную.
- **Журнал** — последние события; кнопки копирования и очистки.
- **Настройки** — источник, автообновление, свои серверы, кэш, логи, удаление
  VPN-профиля.

![Настройки BoVPN](docs/screenshot-settings.png)

## Свои серверы и источник

В настройках можно указать собственный HTTP(S)-адрес CSV или JSON в формате
VPN Gate. Если поле пустое, используются официальный API и резервные зеркала.
Свой источник имеет приоритет; при ошибке приложение возвращается к обычным
источникам.

Серверы, добавленные вручную:

- для SSTP указывайте доменное имя, которое есть в сертификате сервера;
- для L2TP указывайте IP-адрес;
- метка — произвольное имя для списка.

## Где хранятся данные

Всё находится в `%LOCALAPPDATA%\BoVPN`:

| Путь | Назначение |
|---|---|
| `settings.json` | протокол, источник, свои серверы, геометрия окна |
| `cache\servers.json` | кэш списка серверов |
| `cache\native_profile.json` | сведения о последнем VPN-профиле |
| `logs\bovpn.log` | журнал приложения |
| `logs\openvpn.log` | журнал OpenVPN-сеанса |
| `openvpn\*.ovpn` | собранные конфигурации OpenVPN |
| `scripts\*.ps1` | служебные PowerShell-скрипты для UAC |

Пароли не хранятся в файлах BoVPN: на публичных серверах используется общая пара
`vpn/vpn`, и Windows может запомнить её в своём VPN-профиле. BoVPN не отправляет
телеметрию. Для списка серверов приложение обращается к VPN Gate и зеркалам, для
определения внешнего IP — к `api.ipify.org` и `icanhazip.com`.

Android-версия хранит настройки в `SharedPreferences`, а кэш серверов и
подготовленные `.ovpn` — в приватном каталоге приложения. Доступ к файлам
профилей выдаётся только OpenVPN Connect или приложению, выбранному в
«Поделиться».

### Ограничения безопасности

- Публичный VPN **не является анонимным**: оператор видит ваш IP и домены.
- Нет kill switch: при обрыве туннеля трафик может пойти напрямую.
- Возможны утечки через IPv6 и DNS — BoVPN не управляет этими настройками.
- Нет собственного шифрования поверх VPN: защита зависит от протокола и сервера.
- Список серверов и их доступность меняются; часть серверов может не работать.

## Решение проблем

| Симптом / код | Что сделать |
|---|---|
| `691` | Сервер отклонил `vpn/vpn`. Выберите другой сервер. |
| `789`, `809`, `13801` | Провайдер или сеть блокирует L2TP/IPsec. Переключитесь на SSTP. |
| `806` | Сеть блокирует туннель. Попробуйте SSTP и другой сервер. |
| `868` | Не разрешается имя сервера. Проверьте DNS/интернет, выберите другой сервер. |
| `623` | VPN-профиль пропал. BoVPN попробует создать его заново; при повторе удалите профиль в настройках. |
| `720`, `800` | Сервер недоступен. Повторите позже или выберите другой. |
| UAC не появляется | Проверьте, не отключён ли UAC и не блокирует ли запрос антивирус. |
| «Список серверов недоступен» | Нажмите «Повторить», добавьте сервер вручную или укажите свой источник. |
| OpenVPN не найден | Установите OpenVPN Community Edition или выберите SSTP. |
| OpenVPN: нет TAP-адаптера | Переустановите OpenVPN с компонентом TAP-Windows и перезагрузитесь. |
| Windows SmartScreen | EXE не подписан. Можно запустить из исходников или собрать самостоятельно. |
| Android: профиль не открывается | Установите OpenVPN Connect или нажмите «Поделиться», сохраните `.ovpn` и импортируйте вручную. |
| Android: серверы не загружаются | Проверьте интернет и нажмите «Обновить»; зеркала VPN Gate могут быть недоступны. |
| Android: в России не подключается | VPN Gate и OpenVPN блокируются. Используйте Psiphon или Tor/Orbot. |
| Android: кнопка профиля неактивна | У сервера нет OpenVPN-конфигурации. Выберите другой сервер. |

Журнал приложения: `%LOCALAPPDATA%\BoVPN\logs\bovpn.log`. Кнопка «Папка логов»
в настройках открывает её сразу.

## Удаление

1. Отключите VPN в BoVPN.
2. В настройках нажмите «Удалить VPN-профиль» и подтвердите UAC.
3. Удалите папку BoVPN с программой.
4. При необходимости удалите `%LOCALAPPDATA%\BoVPN`.
5. Проверьте «Параметры Windows → Сеть и Интернет → VPN»: профиля **BoVPN**
   быть не должно.

Если профиль остался, его можно удалить вручную в этом же разделе параметров
Windows.

На Android удалите приложение обычным способом; его кэш и профили удалятся
вместе с данными. Профиль, импортированный в OpenVPN Connect, удаляется
отдельно в самом OpenVPN Connect.

## Сборка EXE

Требуется Python 3.10+ и PyInstaller (только для сборки, не для работы):

```bat
python -m pip install pyinstaller
tools\build_exe.bat
```

Готовый файл появится в `dist\BoVPN.exe`. Иконка и версия EXE задаются в
`assets\bovpn.ico` и `tools\version_info.txt`. Для сборки вручную:

```bat
python -m PyInstaller --noconfirm --clean --onefile --windowed ^
  --name BoVPN --icon assets\bovpn.ico ^
  --version-file tools\version_info.txt ^
  --add-data "assets;assets" BoVPN.pyw
```

## Сборка APK

Нужны JDK 17 и Android SDK с платформой API 36 и build-tools 36.0.0. Gradle
wrapper скачает нужную версию сам. Из папки `android`:

```bat
gradlew.bat assembleDebug
```

Debug-APK появится в `android\app\build\outputs\apk\debug\app-debug.apk` и
устанавливается на телефон без дополнительных настроек.

Для release-сборки нужен собственный ключ. Создайте `android\keystore.properties`
(файл исключён из репозитория):

```properties
storeFile=keystore/bovpn-release.jks
storePassword=ваш_пароль
keyAlias=bovpn
keyPassword=ваш_пароль
```

и сам ключ:

```bat
keytool -genkeypair -v -keystore keystore\bovpn-release.jks ^
  -alias bovpn -keyalg RSA -keysize 2048 -validity 10000
gradlew.bat assembleRelease
```

Готовый подписанный файл: `android\app\build\outputs\apk\release\app-release.apk`.
Скрипт `tools\build_apk.bat` собирает release при наличии ключа, иначе debug,
и копирует результат в `dist`.

## Разработка и проверки

```bat
:: запуск из исходников
python -m bovpn

:: демо-режим без сети, удобен для проверки интерфейса
python -m bovpn --demo

:: модульные тесты парсеров и OpenVPN-конфигурации
python -m unittest discover -s tests -v

:: smoke-тест интерфейса в демо-режиме
python tools\smoke_test.py
```

`tools\preview.py` делает скриншоты демо-режима (нужен Pillow). Тесты и
preview не входят в runtime-зависимости приложения.

## Структура проекта

```
BoVPN.pyw               запуск без консоли
BoVPN.bat               запуск EXE или Python
bovpn/
  app.py                главное окно, состояние подключения
  dialogs.py            модальные окна и предупреждение
  native.py             SSTP/L2TP, UAC, rasdial
  openvpn_backend.py    поиск OpenVPN, безопасные конфиги, запуск
  servers.py            CSV/JSON, источники, кэш, свои серверы
  settings.py           настройки и кэш
  ui.py                 тема и виджеты
  util.py               пути, логи, проверки, форматирование
tests/                  модульные тесты
tools/                  сборка, иконка, preview, smoke-тест
assets/                 иконка приложения
android/                исходники Android-приложения
dist/BoVPN.exe          готовая сборка для Windows
dist/BoVPN-android.apk  готовая сборка для Android
```
